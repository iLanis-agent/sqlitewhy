SqliteWhy
You inserted '007' and got 7. You sorted '10' before '9'. SQLite did exactly what its rules say.
Open the app
CREATE TABLE t(zip INTEGER); INSERT INTO t VALUES ('007'); SELECT zip FROM t; 7 text that looks like a number is converted

What it does

  • Gives a column's declared type its affinity and names the rule that decided it (FLOATING POINT contains INT, STRING is NUMERIC).
  • Shows what is really stored for a value: INTEGER, REAL, TEXT, BLOB or NULL, and why.
  • Compares two values the way SQLite does, including the affinity conversions and the number, text, blob ordering.

How far to trust it

  • Compared with real SQLite 3.37.2 on 48,000 generated column types and values with 0 differences. Collations, expressions, STRICT tables and newer versions were not tested.
